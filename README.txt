PORTOFOLIO UTS MATEMATIKA INFORMATIKA — LEVEL 6

ISI FOLDER
- index.html : struktur website dan komponen kalkulator
- style.css  : desain, warna, dan responsivitas
- script.js  : logika kalkulator dengan JavaScript

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder uts_matematika_informatika.
3. Klik dua kali index.html atau buka folder dengan Visual Studio Code.
4. Jika menggunakan VS Code, disarankan jalankan index.html dengan ekstensi Live Server.

FITUR
- Biodata online
- Level 1: Modulo Calculator (termasuk bilangan negatif)
- Level 2: Congruence Checker
- Level 3: Integrasi ke website biodata dan navigasi
- Level 4: Showcase Bukti Belajar
- Level 5: Konversi biner, desimal, oktal, heksadesimal
- Level 6: Permutasi dan kombinasi

SEBELUM DIKUMPULKAN
- Periksa dan sesuaikan nama, NIM, program studi, dan informasi biodata di index.html.
- Uji semua kalkulator dengan beberapa input, termasuk input salah dan bilangan negatif.
- Deploy folder ini ke Netlify atau Vercel agar mendapat URL publik.
- Pahami fungsi-fungsi di script.js karena ketentuan UTS menyebutkan mahasiswa harus memahami logika program.

CATATAN
Website ini menggunakan JavaScript (bukan Java), sesuai instruksi PDF UTS.
Font dari Google Fonts memerlukan koneksi internet; website tetap dapat digunakan tanpa font tersebut.
